### [E-Commerce SQL Database](https://github.com/abdelrhmanmouse/ecommerce-sql-database)

### [SCVD Violence Intelligence Dashboard](https://github.com/abdelrhmanmouse/SCVD-Violence-Detection)

An explainable CCTV video-analysis system that classifies temporal video segments as **Normal**, **Violence**, or **Weaponized Violence**. It uses a ResNet18 and two-layer LSTM pipeline, with incident timelines, probability analysis, person detection in alert scenes, annotated video, and downloadable reports.

`Python` `PyTorch` `ResNet18` `LSTM` `OpenCV` `Computer Vision` `Streamlit`

[Live Demo](https://scvd-violence-detection-m9rb8lphpu2lpth3p97xqr.streamlit.app/)

### [HikAssist — Arabic-Egyptian RAG Assistant](https://github.com/abdelrhmanmouse/simple-rag-lab)

A technical-support assistant for common Hikvision device issues. It combines BM25 keyword retrieval with multilingual semantic embeddings, builds source-grounded context, and generates Arabic answers through an OpenRouter model in a Streamlit interface.

`Python` `RAG` `BM25` `Sentence Transformers` `ChromaDB` `OpenRouter` `Streamlit`

[Live Demo](https://simple-rag-lab-ojndyxhf7bgrvhmuuw3huu.streamlit.app/)
